# PLENOI WIL Career Life Simulator

เว็บเกมจำลองชีวิตฝึกงาน 10 เดือน ใช้ข้อมูลตำแหน่งงานจากไฟล์ปีการศึกษา 2564–2568 จำนวน 584 รายการ

## เปิดเล่น

เปิด Terminal/PowerShell ในโฟลเดอร์นี้ แล้วรัน:

```powershell
python -m http.server 8000
```

จากนั้นเปิด http://localhost:8000

## ในเกมมีอะไรบ้าง

- โปรไฟล์นักศึกษาและอัปโหลด CV PDF เพื่อจับคู่ตำแหน่งจากข้อมูลตำแหน่งงาน
- ศูนย์ฝึกทักษะ Soft Skill และ Hard Skill ก่อนสัมภาษณ์
- ห้องสัมภาษณ์แบบเลือกคำตอบ พร้อม feedback รายข้อ
- 60 เหตุการณ์ระหว่างฝึกงาน 10 เดือน (6 ต่อเดือน) และผลลัพธ์ตามการตัดสินใจ
- ฉาก Pixel Art สร้างจากโค้ดครอบคลุมห้องสัมภาษณ์ ศูนย์ฝึก ออฟฟิศ แล็บ สตูดิโอ ประชุม พื้นที่พบลูกค้า เดโม ส่งมอบงาน และฉากจบ พร้อมสี ตัวละคร เสื้อผ้า และพร็อพมากกว่า 10,000 รูปแบบ
- สรุปจุดแข็ง ทักษะที่ควรพัฒนา และบทสนทนา/เหตุการณ์ประกอบได้กว่า 14.9 ล้านรูปแบบ (60 ฉากหลัก × 12⁵ ชุดบทพูด ตัวละคร แรงกดดัน รายละเอียด และ feedback)
- ฉากจบพร้อมบทสรุปและภาพประกอบ 2,500 รูปแบบ (4 ระดับผลลัพธ์ × 625 บทส่งท้าย/ภาพย่อย)

## ขอบเขตต้นแบบ

เป็นต้นแบบ front-end ที่ทำงานในเบราว์เซอร์ ไม่มีระบบบัญชี ฐานข้อมูลส่วนกลาง หรือระบบนัดสัมภาษณ์กับพนักงานจริง การอ่าน CV ใช้ PDF.js จาก CDN และประมวลผลข้อความในเบราว์เซอร์; ถ้าไม่มีข้อความที่ดึงได้ นักศึกษายังกรอกทักษะด้วยตนเองได้ คะแนนจับคู่เป็น heuristic สำหรับเกม ไม่ใช่การคัดเลือกเพื่อจ้างงานจริง


## ยืนยันว่าเป็นเกมจำลอง

ผู้สัมภาษณ์ โค้ช เพื่อนร่วมทีม ผู้ใช้ และเหตุการณ์ทั้งหมดเป็นตัวละคร/บทบาท AI จำลอง ไม่ได้เชื่อมต่อบริษัทหรือพนักงานจริง ตำแหน่งจาก Excel เป็นข้อมูลย้อนหลังสำหรับสร้างฉาก ไม่ใช่ประกาศรับสมัครหรือคำแนะนำการจ้างงาน การให้คะแนนเป็นกติกาของเกม ไม่ใช่การประเมินคัดเลือกจริง
