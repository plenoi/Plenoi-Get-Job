# Plenoi Get Job

Visual Novel จำลองสหกิจ 10 เดือน เป้าหมาย 299 ตำแหน่ง สาขานี้กำลังกู้ต้นฉบับเพื่อแก้ระบบตัวละคร สถานะ และทักษะ ยังไม่ใช่รุ่นแก้สมบูรณ์และยังไม่พร้อมเผยแพร่

ใช้ Node.js 20+ และ npm start; npm run build สร้าง dist สำหรับ deploy. ต้นฉบับอยู่ใน story-pilot/roles. เก็บรุ่นด้วย Git ไม่เก็บ build หรือ ZIP ซ้ำ.
